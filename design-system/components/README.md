# FreeCAD UI Components

This directory contains component specifications for the FreeCAD Design System.

## Components

- [Button](components/button.md) - Interactive button components
- [Toolbar](components/toolbar.md) - Toolbar and tool button components
- [Dialog](components/dialog.md) - Dialog window components
- [Panel](components/panel.md) - Panel and dock widget components
- [Input](components/input.md) - Input field components
- [Menu](components/menu.md) - Menu and menu bar components
- [TreeView](components/treeview.md) - Tree view component
- [PropertyEditor](components/propertyeditor.md) - Property editor components
