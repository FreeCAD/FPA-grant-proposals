## Quick Reference

### Available Components

| Component | Description |
|-----------|-------------|
| Button | Interactive button components (primary, secondary, icon) |
| Toolbar | Toolbar and tool button components |
| Dialog | Dialog window components |
| Panel | Panel and dock widget components |
| Input | Text, number, and selection input components |
| Menu | Menu bar and dropdown menu components |
| TreeView | Hierarchical data display |
| PropertyEditor | Property editing interface |

### Core Design Tokens

```css
/* Colors */
--color-background-primary: #1e1e1e
--color-accent-primary: #007acc
--color-text-primary: #cccccc

/* Typography */
--font-size-base: 12px
--font-family-primary: "Segoe UI", Arial, sans-serif

/* Spacing */
--spacing-md: 6px
--spacing-lg: 8px

/* Sizing */
--size-button-height: 24px
--size-toolbar-height: 32px
```
